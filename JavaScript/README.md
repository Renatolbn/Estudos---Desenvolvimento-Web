## 📚 Categorias de Exercícios

### Imperativos
Exercícios focados em estruturas condicionais, variáveis e fluxo básico de controle. Contém 11 exercícios (ex06 a ex16) que abordam conceitos fundamentais da programação imperativa.

### Loops
Exercícios dedicados a estruturas de repetição (for, while, do-while). Contém 3 exercícios práticos para dominar o conceito de iteração.

## 🚀 Como Usar

1. Clone este repositório
2. Abra os arquivos `.html` diretamente no navegador
3. Consulte o PDF "Lista de Exercícios" para entender os enunciados
4. Pratique modificando e experimentando com o código

## 🛠️ Tecnologias

- HTML5
- JavaScript (Vanilla)
- ESLint para padronização de código

## 📝 Requisitos

- Navegador web moderno (Chrome, Firefox, Edge, Safari)
- Editor de código (VS Code recomendado)
- Node.js (para executar o ESLint)

## 💡 Dicas de Estudo

- Comece pelos exercícios imperativos antes de avançar para loops
- Tente resolver cada exercício sem consultar soluções prontas
- Teste diferentes inputs para validar sua lógica
- Use o console do navegador (F12) para debugar
- Pratique refatoração após resolver os exercícios
